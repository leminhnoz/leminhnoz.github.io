Đăng bởi: Le Minh NDuc (ldber 29') | Chuyên mục: Announcement & Guide | Đăng ngày: 05/02/2025

Chào mừng bạn đến với nơi mình lưu trữ kinh nghiệm thi đấu, các dạng bài Competitive Programming đã cày và những khung code C++ tối ưu để dùng trong contest.

Hướng dẫn sử dụng web

  1. Mẹo 1 - Search: Gõ từ khóa vào thanh tìm kiếm trên navigation bar để tìm nhanh thuật toán, ví dụ segment tree, freopen, dp.
  2. Mẹo 2 - Modules: Học theo lộ trình từ Module -1 (C++ Basics, operators, ASCII, freopen) đến Module 3 (Dynamic Programming, Graph Theory).
  3. Mẹo 3 - Editorials: Xem lời giải chi tiết gồm đề bài, input/output, chạy tay từng test và code C++.
